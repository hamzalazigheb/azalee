# Instructions pour créer l'image Open Graph

## Spécifications requises

- **Nom du fichier**: `og-image.jpg`
- **Emplacement**: `public/og-image.jpg`
- **Dimensions**: 1200 x 630 pixels
- **Format**: JPG ou PNG
- **Poids**: < 1 MB (idéalement < 300 KB)

## Contenu recommandé

L'image doit contenir:
1. Logo Azalée Patrimoine
2. Slogan: "Gestion de patrimoine et conseil financier"
3. Couleurs de la marque: #253F60 (bleu foncé) et #B99066 (or/bronze)
4. Design professionnel et élégant

## Outils en ligne gratuits

- Canva: https://www.canva.com/
- Figma: https://www.figma.com/
- Adobe Express: https://www.adobe.com/express/

## Template suggéré

```
┌─────────────────────────────────────┐
│                                     │
│        [Logo Azalée Patrimoine]     │
│                                     │
│     Gestion de patrimoine et        │
│      conseil financier              │
│                                     │
│   Expert en optimisation fiscale    │
│                                     │
└─────────────────────────────────────┘
```

## Une fois l'image créée

1. Placer le fichier dans `/public/og-image.jpg`
2. Vérifier que l'URL fonctionne: `https://azalee-patrimoine.fr/og-image.jpg`
3. Tester avec:
   - Facebook Sharing Debugger: https://developers.facebook.com/tools/debug/
   - Twitter Card Validator: https://cards-dev.twitter.com/validator
   - LinkedIn Post Inspector: https://www.linkedin.com/post-inspector/

## Image temporaire

En attendant l'image officielle, vous pouvez utiliser un outil comme:
- https://og-playground.vercel.app/
- https://www.opengraph.xyz/

Ou créer une image simple avec du texte sur fond uni aux couleurs de la marque.
