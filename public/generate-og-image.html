📸 Comment sauvegarder cette image

Méthode 1: Screenshot (Recommandé)

  1. Faites un clic droit sur l'image ci-dessus
  2. Sélectionnez "Inspecter" ou appuyez sur F12
  3. Dans les DevTools, cliquez droit sur <div class="og-image">
  4. Choisissez "Capture node screenshot"
  5. L'image sera téléchargée automatiquement
  6. Renommez-la en og-image.jpg
  7. Placez-la dans le dossier public/

Méthode 2: Outil de capture

  1. Utilisez l'outil de capture Windows (Win + Shift + S)
  2. Capturez uniquement la zone de l'image (1200x630)
  3. Enregistrez sous og-image.jpg
  4. Placez dans public/og-image.jpg
